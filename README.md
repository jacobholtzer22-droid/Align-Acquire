# Align & Acquire Landing Page

A modern, responsive, and conversion-focused landing page for Align & Acquire, a digital agency specializing in website creation and AI automation services.

## Features

- **Modern React + Vite** setup for fast development
- **Tailwind CSS** for styling with brand colors (blue, green, white)
- **Fully Responsive** design that works on all devices
- **Smooth Scrolling** navigation
- **Pricing Toggle** to switch between Basic and Pro plans
- **Contact Form** with validation
- **Conversion-Focused** design with clear CTAs

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
